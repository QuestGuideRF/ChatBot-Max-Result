# ChatBot-Max-Result

ChatBot-Max-Result — Python-проект, который объединяет MAX-бота и систему распознавания лиц с камеры. Он сохраняет эталонные фотографии, отслеживает появление неизвестных лиц, сообщает о блокировке камеры и может отправлять уведомления подписанным пользователям.

## ✨ Возможности

- Детекция лиц через `OpenCV FaceDetectorYN` и модель `face_detection_yunet_2023mar_int8bq.onnx`.
- Сравнение лиц по эмбеддингам через `PyTorch`.
- Запуск MAX-бота и детектора камерой одним процессом через `supermain.py`.
- Сохранение фотографий, отправленных в чат, в папку `data/`.
- Сохранение скриншотов с нераспознанными лицами в папку `foreign/`.
- Отслеживание файлов в папке из переменной окружения `folder` и отправка уведомлений в MAX.
- Уведомление о блокировке камеры.
- Хранение подписанных пользователей в SQLite-базе `users.db`.

## 🚀 Быстрый старт

Перед запуском проект ожидает:

- переменную окружения `TOKEN` с токеном MAX-бота;
- переменную окружения `folder` с путём к отслеживаемой папке;
- файл `models/backbone_ir50_ms1m_epoch120.pth` в каталоге `models/`.

В текущей локальной копии присутствует только модель детекции `models/face_detection_yunet_2023mar_int8bq.onnx`. В исходном README указана ссылка на папку с моделью эмбеддингов: [Google Drive](https://drive.google.com/drive/folders/1omzvXV_djVIW2A7I09DWMe9JR-9o_MYh).

```bash
cd ChatBot-Max-Result
python -m pip install -r requirements.txt
python supermain.py
```

## 📁 Структура проекта

- `supermain.py` — совместный запуск MAX-бота и детектора лиц.
- `test3maxbot.py` — логика MAX-бота, работа с пользователями и отслеживание папки.
- `FaceDetector.py` — основной модуль детекции и распознавания лиц.
- `config.py` — параметры камеры, путей и порога сходства.
- `models/` — модели детекции и распознавания лиц.
- `data/` — сохранённые эталонные изображения.
- `foreign/` — кадры с нераспознанными лицами.
- `users.db` — база подписанных пользователей.
- `requirements.txt` — список зависимостей проекта.

## 🛠 Использование

После запуска через `supermain.py` работают сразу две части проекта:

- поток видеозахвата и распознавания лиц;
- MAX-бот на long polling.

Поддерживаемые сценарии из кода:

- `/start` — добавить пользователя в базу.
- `/help` — показать краткую справку.
- `/stop` — удалить пользователя из базы.
- отправка фотографии в чат — сохранить фото в `data/`.

Что происходит в фоне:

- при обнаружении неизвестных лиц `FaceDetector.py` сохраняет кадр в `foreign/`;
- при появлении нового файла в папке из `folder` бот отправляет уведомление `💢 Обнаружен посторонний` с вложением;
- при блокировке камеры бот отправляет сообщение `🚨 Камера заблокирована!`.

В проекте также есть файлы `main.py`, `findface.py` и `test3maxbot_save.py`, но объединённый запуск бота и распознавания реализован именно в `supermain.py`.
